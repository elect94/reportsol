# 주식 보고서 강의 · ReportSol

AI와 함께 주식 보고서를 만드는 28장 강의와 실습 자료입니다. 이 저장소는 정적 HTML/CSS/JavaScript로 구성되어 서버 없이 GitHub Pages에서 바로 배포할 수 있습니다.

## 실행

- 브라우저에서 `index.html` 열기
- 온라인 배포: GitHub 저장소 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` 선택 후 Save
- 배포 주소: https://elect94.github.io/reportsol/ (Pages 설정/배포가 완료되면 접속 가능)

## 파일 구성

- `index.html`, `styles.css`, `app.js`, `content.js`: 강의 사이트
- `assets/`: 아이콘
- `materials/`: 실습 양식, 강의 파일, 데이터, 프롬프트 및 추가 자료

일부 예제 가격·뉴스는 교육용 가상 자료입니다. 실제 투자 판단에 사용하지 마세요. 원본 콘텐츠 및 파일의 출처/사용 권한은 배포 전에 확인하세요.
