# AI와 나만의 주식 리서치 도구 만들기 · ReportSol

원문의 28장 강의입니다. 앞부분을 보존하고, P02 결과물에서 Sheets·Docs·Firebase를 순서대로 연결하는 3시간 수업으로 업데이트했습니다.

- 배포: https://elect94.github.io/reportsol/
- 원문: https://narnialab.duckdns.org:13961/#slide-12

## 실행
`index.html`을 브라우저에서 열면 강의와 자료실을 사용할 수 있습니다.

## 파일
- `index.html`, `styles.css`, `app.js`, `content.js`: 원문 강의 웹사이트
- `assets/`: 사이트 아이콘
- `materials/`: 원문 자료실의 교재, 연결 안내, 프롬프트, 예제 자료

## GitHub Pages
Settings → Pages → Build and deployment에서 `main` 브랜치와 `/ (root)`를 선택합니다.
