# AI와 나만의 주식 리서치 도구 만들기 · ReportSol

Antigravity를 사용해 애플·마이크로소프트 두 회사의 리서치 도구를 만드는 28장 강의입니다. HTML/CSS/JavaScript 정적 사이트로 구성되어 GitHub Pages에서 호스팅합니다.

## 보기
- GitHub Pages: https://elect94.github.io/reportsol/
- 원본 강의: https://narnialab.duckdns.org:13961/#slide-6

## 로컬 실행
`index.html`을 브라우저에서 열면 강의와 자료실을 이용할 수 있습니다.

## 배포
GitHub 저장소 Settings → Pages → Build and deployment → Deploy from a branch → `main` 브랜치, `/ (root)` 폴더를 선택합니다.

## 파일 구성
- `index.html`, `styles.css`, `app.js`, `content.js`: 28장 강의 웹사이트
- `assets/`: 사이트 아이콘
- `materials/`: 교재, 프롬프트, 실습 자료, PDF/PPTX, 예제 데이터

일부 예시는 교육용 가상 데이터입니다. 투자 판단에 사용하지 마세요.
