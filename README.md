# AI와 나만의 주식 리서치 도구 만들기 · ReportSol

애플·마이크로소프트를 예제로 검색·비교·저장·자동화를 배우는 28장 Antigravity 강의입니다. 원본의 HTML/CSS/JavaScript와 실습 자료를 정적 사이트로 배포합니다.

- 배포: https://elect94.github.io/reportsol/
- 원본 강의: https://narnialab.duckdns.org:13961/#slide-6

## 로컬 실행
`index.html`을 브라우저에서 열면 강의와 자료실을 이용할 수 있습니다.

## GitHub Pages
Settings → Pages → Build and deployment에서 `main` 브랜치와 `/ (root)`를 선택합니다.

## 구성
- `index.html`, `styles.css`, `app.js`, `content.js`: 강의 사이트
- `assets/`: 아이콘
- `materials/`: 원본 자료실이 제공하는 교재·실습 자료
