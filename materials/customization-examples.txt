수정 요청은 기능 하나로 좁히기
Sheets 예시: “Sheets 저장은 됐는데 시트에서 바꾼 메모가 앱에 안 보여. 관심 목록 다시 읽기 버튼에서 실제 시트 값을 가져오고 화면을 갱신해 줘. 두 회사는 유지해 줘.”
Docs 예시: “Docs 저장 버튼을 두 번 누르면 같은 보고서가 두 번 추가돼. 현재 보고서 ID가 있으면 기존 저장을 알려 주고 중복 추가하지 않게 고쳐 줘.”
Firebase 예시: “저장 직후에는 보이는데 새로고침 후 기록이 없어. 새로고침 전후 UID와 읽는 경로를 비교하고, 인증 복원이 끝난 뒤 서버에서 다시 읽게 고쳐 줘.”
커스터마이징 메뉴의 Apps 연결은 에이전트가 외부 서비스를 사용하도록 돕는 기능입니다. 실제 웹페이지 버튼의 실행 코드는 별도로 필요합니다.
Remote Agents 앱 연결과 로컬 IDE의 설치 가능한 도구는 같다고 가정하지 않습니다. Firebase MCP도 AI의 개발 작업 도구이며 웹 SDK·인증·보안 규칙을 자동으로 대신하지 않습니다.
이번 수업은 메뉴 유무에 따른 여러 갈래 대신 Google은 Apps Script, 기록 저장은 Firebase Web SDK 한 경로로 진행합니다.
