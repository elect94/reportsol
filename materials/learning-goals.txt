이 수업에서 배우는 것 / 주식을 몰라도 참여
목표는 종목 추천이나 수익 예측이 아니라, 말로 기능을 요청하고 외부 자료·저장·반복 절차를 연결해 확인하는 능력이다.
한 번의 보고서라면 대화형 AI에 요청하는 편이 간단할 수 있다. 같은 입력 흐름을 반복해서 사용하고 기록을 다시 꺼내려면 도구가 유용하다.
1. 기능을 입력·동작·출력·완료 기준으로 설명한다.
2. 작은 구현마다 직접 조작하고 출처·날짜·단위를 대조한다.
3. Rules로 기준을, Skills로 반복 절차를 재사용한다.
4. Sheets의 목록, 앱의 조회·비교, Docs 문서, Firestore 기록의 역할을 나누어 연결한다.
5. 구체적 증상으로 수정하고 전에 되던 기능을 다시 확인한다.
6. 수동 성공·예약 등록·실제 실행 결과를 구분한다.
Antigravity를 수업 도구로 사용하지만 요구→확인→수정 방법은 다른 AI 코딩 도구에도 활용할 수 있다. 제품별 UI·권한·연결 기능이 같다는 뜻은 아니다.
평가: 직접 조작·수정·재검증·한계 설명. JSON 작성·프롬프트 암기·투자 지식은 평가하지 않는다.
앱 상태는 실제 연결 / 시점 복사 / 로컬 연습 / 미구현 / 미검증으로 별도 판정한다.
