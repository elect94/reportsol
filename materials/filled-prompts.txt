[01] 만들 도구와 완료 기준
준비: 강사가 준비한 시작 프로젝트

그대로 복사할 완성 예시
주식을 처음 접하는 사람이 두 회사 자료를 비교하는 ‘두 회사 리서치 노트’를 만들 거야.
기본값은 애플 AAPL, 마이크로소프트 MSFT, 미국 NASDAQ, USD, 최근 한 달이야. 투자 추천은 하지 않아.
검색→가격→비교→관심 목록→보고서→기록 저장 흐름으로 만들자. 사용자에게 JSON 작성·업로드를 요구하지 마.
기존 파일과 class-setup.txt를 읽고 준비된 연결을 사용해줘. 검색·비교·저장의 완료 기준을 한 문장씩 적어줘.
지금은 요구사항을 정리하고 확인되지 않은 연결은 미확인으로 표시해줘.

예상 결과: 입력과 확인 방법이 있는 짧은 기준 세 개가 나옵니다.
직접 확인: “AAPL을 검색하면 애플이 나온다”처럼 직접 확인할 동작인지 봅니다.
막히면: 길면 “검색·비교·저장 각각 한 문장으로 줄여줘”라고 요청합니다.

①쉬운 한국어·회사명 우선 ②수치에 단위·기준 날짜·출처 ③실제 자료·가상 시연·실패 구분 ④기능 하나 수정 후 같은 조작으로 확인.

예상 결과: 프로젝트 규칙과 기준을 지킨 예시 문장이 보입니다.

앱 이름은 ‘두 회사 리서치 노트’, 검색 예시는 ‘애플 또는 AAPL’, 기본 기간은 최근 한 달로 해줘.
미연결 영역에는 ‘실제 조회 미연결’을 표시하고 JSON 입력은 요구하지 마.

예상 결과: 검색창과 아직 연결되지 않은 영역이 구분됩니다.
직접 확인: AAPL을 입력하고 버튼을 누릅니다. 화면만으로 실제 조회 성공이라 하지 않습니다.
막히면: “현재 시작 방법과 오류를 확인해서 이 프로젝트만 실행해줘”라고 요청합니다.

[03] 실제 종목 검색 연결
준비: 강사가 AAPL·MSFT 조회를 검증한 데이터 연결

그대로 복사할 완성 예시
class-setup.txt의 사전 검증된 제공처로 앱 검색창에 실제 종목 검색을 연결해줘.
애플·Apple·AAPL은 AAPL로, 마이크로소프트·Microsoft·MSFT는 MSFT로 찾게 해줘. 한글 별칭은 편의 기능이고 실제 회사·시장은 제공처로 확인해줘.
결과에 회사명·종목코드·시장을 보여주고 실패를 가상 값으로 채우지 마.
기존 서버를 사용하고 비밀 키를 화면 코드·로그에 넣지 마. 설정이 없으면 필요한 항목만 강사에게 알려줘.
AAPL, MSFT, NO_SUCH_STOCK_123 세 검색과 출처를 직접 확인해줘.

예상 결과: 두 실제 회사는 서로 다른 결과, 없는 종목은 결과 없음이 나옵니다.
직접 확인: 세 검색어를 웹앱에 직접 입력합니다. AI 대화만 바뀌면 미완료입니다.
막히면: 접근 오류는 강사에게 연결 확인을 요청하고 검증된 C1 사본으로 이어갑니다.

[04] 가격·날짜·출처 표시
준비: 실제 검색이 작동하는 상태

그대로 복사할 완성 예시
검색한 회사의 최근 한 달 일별 종가를 조회해 차트·첫 값·마지막 값·변화율을 보여줘.
종가는 ‘그 거래일의 마감 가격’이라고 설명하고 USD·거래일·조회 시각·출처·수정주가 여부를 표시해줘. 모르는 기준은 확인 필요로 남겨줘.
변화율은 (마지막 값/첫 값-1)×100이야. 유효 값 부족·첫 값 0이면 계산 불가로 표시해줘.
회사 변경 시 이전 가격을 지우고 늦게 도착한 이전 요청이 새 화면을 덮지 않게 해줘.
원자료 첫 값·마지막 값을 화면과 대조하고 실제 조회 실패를 그대로 보여줘.

예상 결과: 실제 날짜 범위와 USD가 가격 옆에 보입니다.
직접 확인: AAPL→MSFT로 바꾸어 이름·가격·날짜·출처가 같이 바뀌는지 봅니다.
막히면: 주말의 오늘 가격이 없다고 오류로 단정하지 않습니다. 마지막 거래일과 조회 날짜는 다릅니다.

[05] 같은 출발점으로 비교
준비: 두 회사의 가격 조회가 성공한 상태

그대로 복사할 완성 예시
AAPL과 MSFT를 선택해 최근 한 달의 공통 거래일로 비교하게 해줘.
공통 첫날을 각각 100으로 맞추고 각 날짜 값/공통 첫날 값×100으로 그려줘. 100은 달러가 아니라 같은 출발점이라고 설명해줘.
변화율·실제 기간·통화·가격 기준을 표시해줘. 공통 자료 부족·첫 값 0이면 비교 불가로 안내해줘.
한쪽 조회 실패와 같은 회사 중복 선택을 구분하고 선택을 바꿔도 검색·가격 기능을 유지해줘.
첫날 100과 마지막 값이 원자료 계산식에 맞는지 확인해줘.

예상 결과: 두 선이 같은 출발점 100에서 시작합니다.
직접 확인: 가격이 싼 회사가 좋은 회사라는 뜻이 아닙니다. 같은 기간의 변화만 봅니다.
막히면: 공통 날짜가 없다면 비교 불가 안내가 맞는 결과입니다. 날짜·가격을 지어내지 않습니다.

[X07] 비교 기록 저장 구현
준비: X06 연결 확인 · 현재 비교 자료

그대로 복사할 완성 예시
‘비교 기록 저장’ 버튼을 현재 앱에 추가하고 확인된 로컬 Firestore 에뮬레이터에 연결해줘.
