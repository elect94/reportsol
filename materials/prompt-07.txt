[07] 보고서 작성 버튼
준비: 기본 AAPL/MSFT 비교 자료 · 뉴스는 미연결로 가능
이 단계 기본값: 제목: 애플·마이크로소프트 비교 기록 / 내부 출력: outputs/apple-msft-report.html

그대로 복사할 완성 예시
기본 AAPL·MSFT의 최근 한 달·USD 비교 자료로 ‘보고서 작성’ 버튼을 만들어줘.
제목은 ‘애플·마이크로소프트 비교 기록’, 순서는 비교 대상→가격·변화율→출처·조회 시각→확인한 사실→미확인 사항이야. 뉴스 미연결은 그대로 표시해줘.
같은 조회에는 같은 기록 ID를 쓰고 화면의 동일 수치로 구성해줘. 새 조회는 새 ID로 구분해줘.
프로그램이 outputs/apple-msft-report.html과 outputs/apple-msft-snapshot.json을 내부 생성해 Docs·저장에서 같은 기록을 읽게 해줘. 학생에게 파일 작성을 요구하지 마.
인쇄/PDF 저장을 제공하고 값·날짜·ID를 대조해줘. 자료가 없으면 먼저 기본 조회를 실행하고 값을 지어내지 마.

예상 결과: 동일 기록 ID의 보고서 화면과 내부 출력 파일이 준비됩니다.
직접 확인: 두 회사·USD·조회 시각·ID를 맞춥니다. 학생은 JSON을 만들거나 올리지 않습니다.
막히면: 빈 자료면 “조회 전에는 버튼을 비활성화하고 이유를 보여줘”라고 요청합니다.
