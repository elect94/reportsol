두 회사 리서치 노트 / 기본값이 채워진 과제
사용자: 주식을 처음 접해도 두 회사 자료를 반복 정리해야 하는 사람이라는 수업용 가정.
대상: 애플 AAPL·마이크로소프트 MSFT / NASDAQ / USD / 최근 한 달 일별 종가.
필수: 검색·가격·공통 기간 비교, Sheets 관심 목록, 보고서 작성·Docs 보관, 로컬 Firestore 기록 저장·다시 읽기, 프로젝트 규칙·점검 절차·1회 예약 확인.
사용 흐름: 회사 검색 또는 관심 목록 버튼→두 회사 비교→보고서→검토 후 Docs 보관→비교 기록 저장→새로고침 후 열기.
데이터는 앱 내부에서 처리하고 사용자에게 JSON 작성·업로드를 요구하지 않는다.
Sheets는 에이전트가 읽은 시점의 목록이다. Docs 추가도 에이전트 작업이다. 앱에 Google 권한이 자동 전달되지 않는다.
Firestore는 사전 준비한 로컬 에뮬레이터다. 운영 클라우드·영구 보존·다기기 동기화를 완성했다고 주장하지 않는다.
학습 경로: P01→X01→P02~05→X02~03→P07→X04~05→X06~08→X09~11→P09→P10→X12→P11. P08은 막힐 때.
참고: P06 뉴스, P12 공유 검토. 기본 수업에서 뉴스 연결·배포·장기 예약·로그인·자동 매매는 추가하지 않는다.
3시간: 학습160분+휴식20분, 강사 준비 기반에서 진행하는 제안. 실제 완주 예행연습은 미실행.
현재 제공 예제 research-workbench.html은 가상 JSON을 읽는 보조 자료이며 목표 앱 완성본이나 시작 프로젝트가 아니다.
