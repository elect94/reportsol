AI와 주식 리서치 웹페이지 만들기 / 실습 과제
목표: Antigravity에서 관심 종목의 자료를 수집·검증해 JSON으로 저장하고 준비된 웹페이지에서 검색·보고서 작성을 수행한다.
준비: research-workbench.html, stock-data-example.json, data-format.txt를 같은 실습 폴더에 준비한다.
기본 경로: 프롬프트 01~02 양식 체험 → 03 실제 자료 수집 → 05~07 검증·분석 → 08 종목 추가 → 09 보고서 → 10 검사.
대체 경로: 수집이 막히면 03 대신 04로 가상 자료 사용. 실제 종목에 가상 값을 넣지 않는다.
담당: Antigravity는 수집·분석·저장, 웹페이지는 파일 읽기·검색·보고서 양식 구성.
결과: research-workbench.html + stock-data.json + 선택한 종목의 PDF 보고서.
보고서는 선택 종목의 전체 저장 기간을 사용한다. 기간 변경은 Antigravity에서 자료·분석을 갱신한 뒤 다시 불러온다.
DEMO·SAMPLE은 교육용 창작 회사이며 가격과 뉴스는 실제 자료가 아니다.
범위: 투자 추천·미래 가격 예측·자동 매매·웹페이지의 실시간 인터넷 검색·AI 호출은 포함하지 않는다.
180분 제안: 도입·체험 30분 / 준비 40분 / 수집·검증·검색·보고서 실습 73분 / 확장·마무리 17분 / 별도 휴식 20분.
완료 기준: JSON 불러오기, 이름·코드 검색, 종목 전환, 보고서 작성, 수치·출처 대조, 오류·모바일·인쇄 확인.
