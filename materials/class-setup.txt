강사 준비 / 3시간 제안
1~9페이지는 기존 내용 그대로 유지한다. P02 완료는 HTML 제작·미리 보기까지이며 미배포다. 10페이지에서 이 상태를 확인하고 P03 안에서 연결 코드 준비와 최초 배포를 진행한다.
이후 필수 프롬프트는 03 Sheets → 04 Docs → 05 Firebase 세 개다.
첨부된 현재 HTML은 research-note-start.html로 원본 그대로 제공한다. 기존 결과물이 있는 학생은 그 파일에서 이어 간다.
현재 동작 확인: 기본 예제·비교 차트·보고서 초안·브라우저 임시 저장. 외부 버튼은 아직 안내만 제공한다.
관찰된 한계: 가상 시세 8개씩, 실제 검색 API 없음, 보고서의 110 USD 출처와 20거래일 설명 불일치. P04에서 데이터와 문구를 맞춘다.
수업 시간은 제안이며 실제 계정의 권한 승인 대기와 생성 시간을 보장하지 않는다.
교사는 본인 테스트 계정에서 P03~P05 전 과정을 사전에 실행한다. Google 조직 정책, 나만 접근 배포, Docs 권한, Firebase 프로젝트 생성, 익명 인증, Firestore 규칙, Apps Script iframe에서 UID 유지와 서버 재조회를 확인한다.
실패 학생은 해당 단계의 파일을 점검하고 다음 단계 진입 전에 복구한다. 권한을 우회하거나 전체 공개로 바꾸지 않는다. 시연 관찰은 직접 완료와 구분한다.
필요 준비: Antigravity에서 열 수 있는 현재 HTML, Apps Script·Firebase 사용 가능한 본인 계정, 같은 브라우저, 인터넷. 실제 주가 API·로컬 에뮬레이터·예약 환경은 이번 후반 수업의 전제가 아니다.
자료 제작 과정에서는 실제 Google·Firebase 계정 연결이나 배포를 수행하지 않았다. 실제 연결은 각 수강생의 실습에서 검증한다.
