[X04] Docs 초안 미리 보기
준비: P07의 apple-msft-report.html·apple-msft-snapshot.json
이 단계 기본값: Docs: 리서치 연습 - 비교 기록 / 기본 보고서 1건 미리 보기

그대로 복사할 완성 예시
outputs/apple-msft-report.html과 outputs/apple-msft-snapshot.json의 같은 기록을 읽어줘.
대상은 내 Docs ‘리서치 연습 - 비교 기록’, 제목은 ‘애플·마이크로소프트 비교 기록’, 내용은 AAPL·MSFT 최근 한 달·USD야.
제목→비교 대상→가격·변화율→출처·조회 시각→확인한 사실→미확인 사항→기록 ID 순서의 추가 초안을 보여줘.
동명 문서가 있으면 본인 링크를 한 번 확인하고 이후 같은 문서를 써줘.
지금은 대상·본문 미리 보기만 해줘. 파일이 없으면 P07 보고서부터 준비하고 값·ID를 만들어 채우지 마.

예상 결과: 어디에 무엇이 저장될지 보입니다.
직접 확인: 마지막 값·조회 시각을 화면과 비교합니다.
막히면: 내부 출력 파일이 없으면 P07을 먼저 실행합니다. 서로 다른 ID의 보고서와 수치를 섞지 않습니다.
