강사 사전 준비 / 3시간 초보반 운영의 전제
이 자료는 수업 설계·교재·요청문이다. 실제 시세 연결 시작 앱·Google 권한·Firestore 환경·수강생별 3시간 완주는 아직 검증되지 않았다.
학생에게는 빈칸 없는 기본 예시를 제공한다. 아래 미확정 기술 조건은 강사가 수업 전에 실제 확인하고 class-setup.txt에 기록한다.

1. 시작 프로젝트 C0 준비
기존 실행 구조·데이터 조회 클라이언트·필요한 패키지를 설치한 상태를 준비한다. 학생은 빈 검색/비교 화면을 P02부터 완성한다.
데이터 제공처는 AAPL·MSFT의 종목 검색과 최근 한 달 일별 종가를 실제 응답으로 확인한 한 곳만 쓴다. 현재 제공처는 미확정이다.
검색·가격이 무료·무제한·실시간이라고 가정하지 않는다. 공식 문서·사용 권한·요금·호출 제한·수업 인원 요청량을 확인한다.
키가 필요하면 승인된 서버 설정으로 준비하고 비밀 값은 자료·화면·대화에 넣지 않는다. AI의 웹 검색 결과를 앱 API로 오해하지 않게 한다.
C0는 처음부터 아무 설정 없는 빈 폴더가 아니다. 초보반이 3시간 안에 응용까지 경험하도록 설치·연결 기반을 준비한 시작점이다.

2. 실제 검증 사본 C1 / C2
C1: 실제 AAPL·MSFT 검색·최근 한 달 가격·공통 기간 비교가 동작한 복구 사본.
C2: C1에 보고서·로컬 Firestore 쓰기/읽기·중복 방지를 확인한 복구 사본.
두 사본 모두 현재 꾸러미에는 포함되지 않는다. 아래 강사 준비 요청문을 본인 수업 앱 프로젝트에서 실행해 준비한다.
학생별 사본을 제공할 때 비밀 값·다른 학생 기록을 포함하지 않는다. 강사 준비본으로 이어간 기능은 ‘도움받아 성공’으로 기록한다.

3. Google 앱 경로 하나를 확정
설치 제품(App/IDE/Remote)·버전·사용할 계정을 기록하고 실제 도구 목록에서 시트 읽기와 Docs 읽기/쓰기 지원을 확인한다.
Remote Agents의 Google 앱 플러그인 경로와 Workspace 개발자 프리뷰 MCP 구성은 다른 준비 경로다. 모든 학생에게 프리뷰 가입·Cloud 설정을 요구하지 않는다.
본인 수업용 시트 A1:E3을 읽고 본인 빈 Docs에 시험 본문을 쓰고 다시 읽는 데까지 확인한다. 계정마다 메뉴와 권한이 다를 수 있다.
로컬 앱 개발 세션과 Google 연결 원격 세션이 다르면 학생 이동 순서를 확정한다.
이때 Sheets 값·보고서가 어느 프로젝트에 있는지 명확히 전달한다. 비민감 자료만 수업에서 승인한 경로로 교환한다.
연결된 앱이 로컬 파일에 자동 접근한다고 가정하지 않는다. 강사 예행연습에서 이 인계 시간까지 잰다.

4. Firebase는 로컬 에뮬레이터로 고정
현재 공식 요구 버전에 맞는 Firebase CLI·실행 환경·SDK를 사전 설치하고 호환성을 확인한다. 학생 수업 중 설치·결제·클라우드 프로젝트 생성을 하지 않는다.
프로젝트 ID 제안은 demo-study-desk. demo- 프로젝트는 운영 자원이 없는 연습 모드다. 코드·CLI의 ID를 맞추고 미가동 에뮬레이터를 운영 연결로 대체하지 않는다.
브라우저는 기존 앱 서버를 통해 로컬 저장소에 접근한다. 원격 환경에서 브라우저의 localhost를 서버 주소로 사용하지 않는다.
현재 환경의 기존 시작 스크립트·고정 주소·HTTPS 규칙을 유지한다. 에뮬레이터 관리 포트를 불필요하게 외부 공개하지 않는다.
학생별 프로젝트·데이터를 분리한다. 한 공유 저장소를 인증 없이 공개하지 않는다. 이번 검증은 브라우저 새로고침이며 종료 후 보존은 별도 import/export 준비다.

5. 예약과 복구 확인
현재 대화에서 수동 ‘리서치 점검’ 성공→2분 뒤 1회 등록→실제 결과를 확인한다.
지원되지 않거나 로컬 앱 접근이 불가능하면 접근 가능한 시트·내보낸 기록만 점검하도록 범위를 명확히 기록한다. 이를 실시간 앱 자동화로 소개하지 않는다.
확정된 제품에서 가능한 경로로 수업안을 고정한다. 현재 제공 자료의 예약은 실행되지 않았다.

6. 시간 운영 / 운영 제안이며 실제 예행연습 필요
P02~P05 생성 대기를 포함해 35분 안에 C1까지 갈 수 있는지 사전 측정한다.
Google 35분에는 이미 연결된 계정과 이미 만든 연습 시트·문서를 사용한다.
Firebase·반복 점검 35분에는 이미 설치된 에뮬레이터를 쓴다. 3시간 안에 모든 것을 처음 설치하는 수업이 아니다.
지연되면 뉴스·배포를 추가하지 않고, C1/C2에서 기능 하나를 수정해 응용 참여를 유지한다.
실제 연결이 막힌 학생은 강사 시연을 관찰할 수 있으나 직접 실습 성공으로 표시하지 않는다.

강사 준비 요청문 / 현재 교육자료 폴더가 아니라 본인 수업 앱 프로젝트에서 사용
주식 초보자를 위한 ‘두 회사 리서치 노트’ 3시간 수업의 시작 프로젝트를 준비해줘.
기본값은 AAPL·MSFT, NASDAQ, USD, 최근 한 달 일별 종가야.
현재 작업 폴더와 기존 실행 규칙을 먼저 읽고 기존 파일을 보존해줘.
공식 자료로 사용 가능한 데이터 제공처의 권한·요금·제한을 확인해줘. 미확정 접근·비용이 있으면 나에게 구체적 선택 조건을 알려줘.
승인된 연결에서 실제 두 종목 검색·가격·비교를 구현하고 원자료 대조, 없는 종목, 한쪽 실패를 검증해줘.
로컬 Firestore demo-study-desk 연습 환경에서 기록 ID로 저장·중복 방지·새로고침 재조회를 구현해줘. 운영 클라우드는 만들지 마.
C0 시작 기반, C1 비교 성공, C2 저장 성공 사본을 기존 파일 삭제 없이 구분해서 준비해줘. 비밀 값은 사본에 포함하지 마.
내 실제 Google 도구에서 수업용 시트 읽기·Docs 쓰기를 지원하는지 확인하고, 외부 쓰기는 대상·본문을 보여준 뒤 내 승인 범위에서 시험해줘.
검증한 실행 방법·실제 주소·사용 도구·제공처·기능별 결과를 class-setup.txt에 기록해줘. 확인하지 못한 것은 확인 필요로 남겨줘.
