AI와 주식 리서치 웹페이지 만들기 / 2026-11-07
1. ZIP 전체를 풀고 index.html을 열면 강의 28장·실습 자료실이 열린다.
2. materials/research-workbench.html을 브라우저에서 연다. JSON 불러오기에서 materials/stock-data-example.json을 선택한다.
3. DEMO 검색 → 결과 선택 → 보고서 작성 → 인쇄/PDF 저장을 체험한다. SAMPLE로 전환하면 통화·가격·누락 안내가 달라진다.
4. Antigravity에서 본인 실습 폴더를 열고 양식 HTML·예제 JSON·data-format.txt를 준비한다. 웹페이지는 서버 없이 직접 열 수 있다.
5. 프롬프트 01~02 준비·체험, 03 수집·JSON 저장, 04 수집 실패 시 가상 연습, 05~07 검증·분석, 08 추가·갱신, 09 보고서, 10 검사 순서다. 11~12 공유는 선택이다.
6. 실제 자료는 본인이 고른 회사·시장·기간·질문으로 Antigravity에서 수집한다. 접근 여부는 환경에 따라 다르며 찾지 못하면 missing에 남긴다.
7. stock-data.json을 양식에서 불러온다. 이름·코드로 저장된 종목만 검색된다. 새 종목은 먼저 수집·저장해야 한다.
8. 보고서 작성은 선택 종목의 전체 저장 기간으로 계산하고 저장된 분석을 배치한다. 버튼이 인터넷에서 자료를 찾거나 AI를 호출하지 않는다.
9. 자료·분석 갱신은 Antigravity에서 JSON 수정 후 다시 불러오기. 새로 열거나 새로고침하면 파일을 다시 선택한다. 업로드·서버 저장은 하지 않는다.
10. DEMO·SAMPLE 가격·뉴스는 교육용 창작이다. 실제 회사의 자료로 표시하지 않는다. 기존 report-example.html/PDF는 DEMO 내용 대조용 정적 보고서다.
11. data-format.txt는 JSON 규칙, data-dictionary.txt와 analysis-answer.txt는 DEMO 원자료 검증용이다. 기사 본문은 news-01.txt·news-03.txt이며 N02는 제목만 제공된다.
12. lecture.pptx는 편집용, lecture.pdf는 인쇄용. 180분은 제안이며 학습 160분+휴식 20분이다. 실제 수집 속도에 따라 조정한다.
13. 활동지는 현재 브라우저에만 저장된다. 다른 기기로 옮길 때 TXT로 내려받는다. 공개 게시·유료 서비스 연결은 기본 실습에 포함하지 않는다.
