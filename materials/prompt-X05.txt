[X05] 검토한 Docs에 추가
준비: X04의 본인 문서 링크·동일 ID 초안을 확인한 뒤
이 단계 기본값: 쓰기: 확인한 동일 문서 끝 / 같은 ID는 1건 / 공유 변경 없음

그대로 복사할 완성 예시
X04에서 내가 확인한 내 Docs ‘리서치 연습 - 비교 기록’과 ‘애플·마이크로소프트 비교 기록’ 초안을 승인해. 그 문서 끝에 한 번 추가해줘.
outputs/apple-msft-snapshot.json과 같은 기록 ID·수치를 사용해줘. 이전 확인 이후 조회 자료가 달라졌다면 새 초안을 다시 보여줘.
기존 본문을 보존하고 같은 ID가 있으면 중복 추가하지 마. 공유 변경·발송은 하지 마.
문서를 다시 읽어 AAPL·MSFT·기간·USD·조회 시각·ID를 대조하고 링크를 알려줘.

예상 결과: 본인 문서 끝에 검토한 내용이 한 번 추가됩니다.
직접 확인: 직접 문서를 열어 봅니다. Docs는 편집, Drive는 파일 보관을 맡습니다.
막히면: 권한이 없으면 PDF로 보관하되 Docs 성공으로 표시하지 않습니다.
