[11] 결과를 네 문장으로 설명
준비: 두 회사 리서치 노트의 실제 확인 결과
이 단계 기본값: 발표: 불편 → 요청 → 실제 변경 → 실제 확인

그대로 복사할 완성 예시
‘두 회사 리서치 노트’ 결과를 네 문장으로 정리해줘.
불편은 ‘애플·마이크로소프트의 최근 한 달 자료를 여러 창에서 반복해 찾기 번거롭다’, 요청은 ‘기본 예제 버튼으로 비교·보고서·저장을 이어 쓰기’야.
변경과 확인 문장은 실제 작업 결과로 채우고, 못 한 기능은 미완료로 적어줘.
Sheets의 시점 복사, Docs 문서, 로컬 Firestore 기록, ‘리서치 점검 1회’ 결과를 구분해줘.
재실행 방법과 기본값을 적고 비밀 값은 제외해줘. 다른 업무 예시는 교육용 ‘무선 마우스 A·B 비교’로 한 문장만 설명해줘.

예상 결과: 반복 작업을 어떻게 줄였는지 설명할 수 있습니다.
직접 확인: 보지 않은 성공·성과를 적지 않습니다.
막히면: 발표가 어려우면 누른 버튼과 달라진 화면을 보여줍니다.
