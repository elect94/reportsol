[X07] 비교 기록 저장 구현
준비: P07의 실제 AAPL/MSFT 스냅샷 · X06 연결 확인
이 단계 기본값: 저장: 보고서와 같은 실제 ID / comparison_records

그대로 복사할 완성 예시
‘비교 기록 저장’ 버튼으로 outputs/apple-msft-snapshot.json의 AAPL·MSFT 최근 한 달·USD 기록을 로컬 demo-study-desk의 comparison_records에 저장하게 해줘.
문서 ID는 보고서의 실제 기록 ID로 하고 회사·기간·가격·변화율·단위·출처·조회 시각·저장 시각을 함께 보관해줘.
같은 조회를 두 번 저장해도 한 개, 새 조회는 새 ID가 되게 해줘. JSON은 프로그램 내부 처리야.
저장 중·완료·실패를 구분하고 쓰기 성공 후에만 완료 표시해줘.
저장소에서 같은 ID를 읽어 보고서·Docs와 대조해줘. 보고서가 없으면 P07부터 준비해줘.

예상 결과: 완료 표시와 저장소 기록이 일치합니다.
직접 확인: 같은 보고서로 두 번 눌러 중복 기록이 늘지 않는지 봅니다.
막히면: 화면에 카드만 추가해 성공으로 처리하지 않습니다. 실제 쓰기 응답을 확인합니다.
