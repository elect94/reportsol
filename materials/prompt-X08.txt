[X08] 새로고침 후 기록 읽기
준비: comparison_records에 저장된 AAPL/MSFT 기록
이 단계 기본값: 기록 목록: AAPL·MSFT / 저장 시각 최신순 / 최대 5개

그대로 복사할 완성 예시
로컬 demo-study-desk의 comparison_records를 읽는 ‘최근 비교 기록 열기’ 버튼을 만들어줘.
기본 대상은 AAPL·MSFT 기록, 정렬은 저장 시각 최신순, 표시 수는 최대 5개로 정해줘. 가장 최근 기록을 먼저 열어줘.
제목은 ‘애플·마이크로소프트 비교 기록’, 안내는 ‘저장 당시 기록’으로 해줘. 기간·USD·ID·수치·저장 시각을 표시해줘.
페이지 새로고침 후 같은 ID·수치가 읽히는지 확인하고 빈 목록·읽기 실패를 구분해줘.
에뮬레이터 재시작 후 보존은 별도 설정 없이 보장하지 마.

예상 결과: 최근 비교 기록 열기에 최신 AAPL/MSFT 기록이 먼저 보입니다.
직접 확인: 새로고침 후 ID·값 하나를 맞춥니다. 표시 상한은 5개이며 기록이 1개면 1개만 보입니다.
막히면: 브라우저 새로고침과 에뮬레이터 재시작은 다른 시험입니다.
